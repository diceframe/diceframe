# 模组与冒险故障排查

## 导入或安装被阻断

先在 **模组 → 导入本地模组** 选择文件并运行“预览安装影响”。预览中的阻断项必须先解决；常见原因包括文件不是有效 `.dfplugin`、DiceFrame 版本不满足要求、缺少规则运行时，或冒险格式不受目标规则支持。

不要改名、解压后手动复制文件来绕过预览。重新取得正确的模组包，或选择满足要求的 DiceFrame 与规则版本。

## 存档提示模组缺失

这表示存档依赖的模组没有安装、已禁用，或所装内容不再满足绑定条件。使用游戏面板的“前往模组库”，按显示的冒险 ID 和版本导入正确模组；安装完成后返回游戏刷新。

## Adventure 内容版本不一致

存档记录了冒险版本和内容摘要。若当前包不同，DiceFrame 不会继续使用它，因为剧情节点、NPC 数据或遭遇可能已经变化。

处理方法是安装与存档匹配的版本。当前不会自动恢复旧版、自动替换内容或把存档迁移到新包；这些将来若提供，必须是可检查的显式流程。

## D&D 2014 / 2024 不匹配

检查模组要求的规则运行时与创建游戏时选择的规则。2014 与 2024 不可互相假定兼容。请安装或选择匹配的运行时；不要把不匹配的包当作普通内容继续开团。

## 无法更新、禁用或卸载模组

这是绑定存档保护。打开模组详情，查看“使用中的存档”，确认哪些游戏仍引用它。保留这些存档时不要强制删除内容；如确需更换内容，应先为每份存档选择并完成一个明确的兼容/迁移方案。

## 玩家看不到内容，或担心秘密泄露

玩家只会收到公开冒险投影。GM 面板与玩家面板不同是正常行为。若公开内容本身缺失，先确认游戏绑定、已安装版本和刷新状态；不要通过直接访问冒险文件或把 GM 数据复制给玩家来修复。

## 需要提交问题时

记录但不要公开分享敏感内容：模组 ID、版本、DiceFrame 版本、规则运行时、安装预览的阻断码，以及是否已有绑定存档。不要上传含 GM 私密内容、存档、访问令牌或第三方受版权保护的完整材料，除非对方有明确安全的提交渠道。
