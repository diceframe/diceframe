# 冒险与创建游戏

## 从模组开始一局冒险

1. 先在 **模组** 页面安装并预览兼容的内容包。
2. 打开 **创建游戏**，选择规则和游戏模式。
3. 选择已安装模组提供的冒险。
4. 检查冒险与当前规则、世界的兼容性。
5. 创建或选择角色，完成开团设置后开始游戏。

创建游戏时，DiceFrame 会把冒险的身份、版本和内容摘要绑定到这份存档。它还会通过既有世界与规则入口准备所需内容。游戏里的 NPC、地点、关系、任务进度和其他变化保存在游戏存档中；不会反向修改原始模组。

## 冒险面板

绑定 v2 冒险后，游戏界面会显示冒险面板。

- GM 可以看到完整的图定义，例如章节、节点、目标、里程碑、场景引用和遭遇引用。
- 玩家与旁观者只会看到公开章节、公开节点和公开目标；隐藏内容及通向隐藏内容的跳转在服务端投影时就会被移除。
- 旧版 v1 冒险仍可正常作为绑定内容使用；面板会明确说明它尚没有 v2 图面板。

当前面板是定义浏览器，不会声称已经持久化 v2 进度或自动执行结果。不要把面板中的节点当成绕过 GM、规则运行时或世界状态的控制器。

## 绑定为什么重要

同一存档必须继续使用相同的冒险版本与内容摘要。若安装的内容不同，DiceFrame 会停止展示可继续使用的内容，而不是让剧情、NPC 或遭遇在旧存档中悄悄变化。

这同样保护回滚与重开：它们应回到与存档一致的内容，而不是切换到后来安装的版本。

## 找不到或不兼容怎么办

游戏中的冒险面板会显示所需的冒险 ID 与版本，并提供“前往模组库”。在模组库中：

1. 导入或安装包含该冒险的正确版本模组。
2. 使用安装预览确认没有阻断项。
3. 返回游戏并刷新。

DiceFrame 不会自动降级、自动迁移或用近似版本替代。将来若有旧版本库或迁移流程，也必须是明确选择并经过检查的操作。

## 公开内容、手册与遭遇

玩家只应依据游戏中公开显示的目标、线索和手册行动。GM 私密信息、未公开遭遇或世界内部过程不应通过截图、链接或前端缓存共享给玩家；权限边界由服务器负责，而不是依赖客户端隐藏按钮。
