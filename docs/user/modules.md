# 模组使用指南

模组是安装到 DiceFrame 的内容包；它可以提供一个或多个冒险，以及可复用的 NPC、怪物、物品、遭遇、地图和场景资料。模组是内容，不是可执行脚本：普通内容模组不能直接运行 Python、JavaScript 或 Shell。

## 模组、冒险和内容库

- **模组**：你安装的完整内容包。
- **冒险**：模组中可在创建游戏时选择的剧情与场景结构。
- **内容库**：冒险可引用的 NPC、物品、遭遇、地图等可复用资料。

安装模组不会修改已有存档，也不会把整包内容一次性塞入 AI 上下文。DiceFrame 会按当前场景、地点、角色、冒险和世界状态取用所需资料。

## 安装本地模组

1. 在导航中打开 **模组**。
2. 在“导入本地模组”选择 `.dfplugin` 文件。
3. 选择“预览安装影响”。
4. 阅读阻断项与警告；有阻断项时不要安装。
5. 确认没有阻断项后选择“安装模组”。

预览会检查模组的内容格式、DiceFrame 版本要求、规则运行时和冒险兼容性。安装成功后可在模组列表打开详情，查看其冒险、内容数量、兼容性和正在使用它的存档。

## 自动化等级

- **参考**：提供剧情、场景与资料；GM 或 AI GM 仍需裁定较多细节。
- **引导**：提供冒险流程、部分目标和遭遇的结构化指引。
- **确定性**：关键遭遇、规则引用、世界状态、目标与里程碑可由 DiceFrame 的既有规则和世界系统更严格地处理。

自动化等级不会让模组获得规则执行权；规则判定仍由所选规则运行时负责。

## D&D 2014 与 2024

D&D 5e 2014 与 D&D 2024 是不同的规则运行时。若模组声明要求其中一个，DiceFrame 不会把另一个静默当作兼容。请在安装预览和创建游戏时检查规则要求；转换是未来的显式人工审查流程，不会自动发生。

## Homebrew、Foundry 与 PDF

Homebrew 可以作为数据模组提供，并按内容类型交给 DiceFrame 的相应系统处理。

DiceFrame 原生模组是当前可直接安装的格式。Foundry 冒险/内容和 PDF 的辅助导入属于未来功能：任何转换都必须先形成可审查草稿，未知规则不会直接被当成可运行内容。

## 为什么不能更新、禁用或卸载？

当已有存档绑定了某个模组中的冒险时，DiceFrame 会阻止会改变该内容的更新、禁用或卸载，并显示受影响存档。这样可以保证下次打开或重开存档时，看到的仍是同一版本的冒险内容。

若要处理这些操作，先在模组详情的“使用中的存档”确认范围；不要通过删除文件绕过保护。

## 隐私与秘密

模组与冒险可标注公开或 GM 私密内容。普通玩家不会从冒险面板或游戏 API 获得 GM 私密节点、目标、章节，或指向隐藏节点的线索。秘密成为公开信息时，应由游戏中的明确状态与叙事流程处理。
