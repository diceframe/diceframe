# 内容、角色与游玩

[English](../en/content-and-play.md) | 简体中文

本页介绍当前程序的内容与游玩流程。已有安装升级前请先看[应用更新](updates.md)。

## 从哪里进入

| 导航 | 内容 |
| --- | --- |
| 总览 | 创建新冒险、继续最近存档。 |
| 游玩 | 当前对局、行动输入、队伍与 GM 工作台。 |
| 角色 | 可复用的角色卡库与本局角色。 |
| 内容 | 内容库、世界资料、内容包、规则。 |
| 管理 | 记忆、日志、插件、设置。 |

在**内容 → 内容库**的工具栏打开世界画廊、冒险工作台、剧本导入和来源管理；世界和冒险不再单列为顶部导航页。可通过搜索和内容语言筛选缩小卡片范围。邀请链接打开的玩家页面只提供该玩家有权使用的操作。

## 世界、资料册、规则和冒险分别做什么

| 内容 | 用途 |
|---|---|
| 世界 | 一局游戏的场景与身份，包含背景、默认规则及关联资料册 |
| 资料册 | 按需给 GM 提供人物、地点、物品、势力和背景知识 |
| 规则 | 决定检定、角色和战斗的权威能力；翻译名称不会改变机制 |
| 冒险 | 带版本的剧情图，包含场景、目标、分支和可选遭遇 |
| 内容包 | 可以安装的来源，提供冒险及可复用资源 |

世界的简短介绍是设定摘要，详细知识通常来自资料册。安装内容包不会把整包资料一次性塞入每次模型请求。

在**内容库**浏览世界、冒险和资料册。世界卡片可以开局或管理资料册；世界画廊还提供预览与**克隆世界**，克隆后获得可编辑的个人世界。

资料册卡片保留资料册自己的标题，并单独标明所属世界。用世界名称初始化的主资料册会加上“主资料册”标识，独立资料册另行标注；这些展示不会重命名已保存的数据。

在**世界资料**中，当前资料册列表按当前世界/游戏范围及所选内容语言显示。从内容库直接打开独立资料册时，只补入链接指定的那一本；切换世界或语言到另一世界会清除旧资料册、旧条目的链接目标，不改变正在游玩的存档。

**设置 → 通用 → 系统语言**与右上角的语言选择同步，保存在当前设备。**设置 → 通用 → DF Agent**单独调整 Agent 每次模型请求的最大输出 Token（默认 4096）。Agent 使用主模型，内容生成工具保留各自预算；这不是整项任务的累计 Token 或费用上限。上下文、采样与独立检定模型的用法见 [AI 与界面设置](ai-settings.md)。

创建游戏可以选择世界模板、自定义或 AI 生成草稿。整理后的界面保留常用选择，语言、种子、补充背景及本局资料册选择放在展开设置中。勾选本局使用的资料册只改变本局绑定；编辑共享来源资料册可能影响同样引用它的其他游戏，需要独立内容时应先复制。

标准自由对局使用普通 GM 叙事；冒险模式沿所选冒险和支持的规则推进。服务端检查兼容性，不会把 D&D 2014 模组悄悄转换成 D&D 2024。

切换到模组冒险后，先选择冒险包，再检查它所需的规则与世界。尚未选择时只提示选择冒险包；已选但不兼容时才提供调整来源、规则或世界的操作。

## 安装或制作冒险

1. 打开**内容 → 内容包**，或从内容库进入来源管理，选择在线内容或本地 `.dfplugin` 文件。
2. 预览安装影响，解决阻断项后确认安装，检查完成状态或错误提示。
3. 打开包详情，选择冒险并点击**用此冒险开局**。
4. 检查世界、规则、资料册和角色，再开始游戏。

从**内容 → 内容库**进入**冒险工作台**，可以新建冒险、AI 生成草稿、导入原生冒险包、导入剧本与外部模组，或整理现有文字。存档绑定冒险身份、版本和摘要；会破坏绑定的更新、禁用和卸载操作会被阻止。先查看受影响存档，不要直接删包文件绕过保护。

## 导入剧本、PDF 或外部模组

导入页支持 UTF-8 Markdown/TXT、Foundry Adventure 导出 JSON、未加密 Fantasy Grounds XML/`.mod`，以及有文字层的 PDF。它把本地数据读成草稿，不执行模组脚本、不安装整个 Foundry 系统、不读取任意 LevelDB 合集、不下载外部附件。扫描 PDF 需要先 OCR。

1. 选择文件并解析，检查章节、场景、GM 备注、资源和引用。
2. 修改草稿和可见范围。导入内容默认仅 GM 可见，需要公开的内容应明确设为公开。
3. 解决错误；未解析的人物、地点和遭遇引用会阻止发布，也可以明确选择仅保留为文字。
4. 编辑后重新校验，查看发布检查项并确认审核；页面会说明**发布为冒险**为何不可用。
5. 发布有效草稿，再用这个冒险创建游戏。

外部正文中的数值保持为参考资料，不会自动把怪物、法术、奖励或房规变成可执行机制。

**AI 整理草稿**是可选项，使用设置中的主模型，把正文发给该服务商并消耗 token；启动前需要确认用量提示。进度条表示已完成的步骤，不保证耗时。取消或关闭导入窗口会中止待处理工作，已完成的调用仍可能计费。先查看生成结果，明确采用后才替换当前草稿；失败、取消和未采用的结果不会覆盖编辑内容。采用后仍需重新校验和确认发布。

## 冒险分支与秘密

GM 查看完整冒险，玩家只收到公开投影。原生排他选择可以收集玩家提议，由 GM 确认后提交一条分支；服务端校验当前局次和状态，过期提议不能推进另一局。

文字标记 `@choice 描述 -> 场景ID` 定义剧情连接，多条无条件连接可能同时开放；单靠这个标记不声明原生排他选择组。需要互斥分支时，在冒险编辑器配置结构化选择。

## 角色卡、邀请与 AI 席位

**角色卡库**保存可复用卡片，**本局角色**管理当前游戏里的参与者。已行动角色采用卡片需要 GM 权限。角色模板和角色在一局中的实际状态用途不同。

在游玩页队伍成员列表下点击**邀请好友**，分享真正的邀请链接，玩家直接打开即可；也可以回到首页点击**加入好友**，粘贴完整链接。邀请弹窗中的**联机帮助**会打开官方联机文档。普通邀请链接通常是 `#/join?game=...` 形式，玩家不需要从链接提取并手输 `web|房间|房主`，也不需要配置模型。邀请和席位凭据遵守服务端访问策略，旧链接中的裸玩家 ID 不再算凭据；旧链接无法认证时，请 GM 重新邀请。需要实验性客户端直连时，房主从首页**加入好友 → 更多连接方式 → 发起直连（实验性）**进入高级入口；`DFP2-...` 直连码与普通邀请链接用途不同。

GM 可点击每位队伍成员卡片右侧的 **⋯ 成员操作**，使用操作链接、编辑、暂离/返回、AI 控制切换及踢出。菜单按当前成员状态显示可用操作；踢出位于分隔线下方，采用危险色并要求再次确认，不能踢出房主或当前角色。工作台玩家列表保留状态和休息提示，成员管理统一使用队伍卡片菜单。

菜单中的**操作链接**让玩家接管对应的已有角色；列表底部的**邀请好友**用于新人加入。已有席位链接需要重新生成时会先确认；本次会话里再次打开有效链接会复用，不会使玩家下线。普通玩家看不到这些管理入口。

AI 托管角色与同伴沿用人类玩家的服务端行动和规则边界，其策略随存档保存；叙事不能自行赋予私密信息，也不能绕过资源扣减。

## 检定与战斗

角色有技能时，行动描述输入框内部右侧、行动按钮上方提供**本次技能**，点击后向上展开可选技能，不挤占对话区。可以保持自动判断，
也可以从角色卡中明确选择；明确选择优先于模型猜测，加值仍由服务端按当前规则计算，
技能说明不会自动变成任意数值奖励。失败草稿会在本浏览器为同一游戏、局次、角色和回合
保留所选技能。明确选择只用于本次行动，提交成功后恢复“自动判断”，下次行动不会沿用上次技能；已提交但后续生成失败时，刷新确认后也会恢复。尚未确认结果的草稿保留选择，方便核对或重试。选择后自动折叠选项，在按钮内显示所选技能，列表不会持续占用对话区。

新建游戏默认自动揭示骰子。在游玩页打开 **GM 工作台 → 规则 → 检定流程 → 骰子揭示方式**，
可以选择自动或点击共享揭示。明确选过的方式在读档和重开后保留，升级也保留已有选择。
揭示只改变表现，不改变服务端骰面。

**设置 → 游戏** 位于“通用”下面，集中保存新对局默认：骰子揭示、孤注一掷、快捷行动建议、幸运选择等待时长、
叙事视角与表现、跟随世界或自定义文风，以及支持规则中的成长方式与升级批准方。
新建对局会复制默认值，开局页的明确选择优先；修改默认不追改已有对局或导入存档。
本局修改保存在存档中，重开、重置及引用码重开保留原局偏好。文风选“跟随世界”时仍使用所选世界的设定。

行动面板标题旁的 **快捷建议** 可以隐藏或显示固定及本轮生成的建议按钮，每位玩家独立选择。选择保存在当前设备的浏览器中，按对局和角色区分，刷新、进入下一轮或重新开局后仍保留；不会影响其他玩家，也不会停止生成建议。隐藏后仍可自然语言输入行动、选择本次技能。

**GM 工作台 → 设置 → 行动面板 → 默认显示快捷行动建议** 设置本局的初始显示状态；**设置 → 游戏 → 行动面板** 设置新对局默认。默认开启，旧存档缺少此设置时也沿用开启。玩家自己的选择优先，GM 修改默认不会覆盖。如果正在运行的后端还未加载新字段，默认开关会提示重启服务，不提交后端不支持的字段；玩家的个人隐藏／显示仍可使用。

支持孤注一掷的规则下，**GM 工作台 → 规则 → 检定流程 → 允许孤注一掷** 默认开启。
关闭后不再创建这类选择，尚未完成的申请接受原检定结果并保留记录，已完成的重掷结果不变；
重新开启不会重开旧申请。幸运选择独立处理。最后一个阻塞选择结束后会尝试沿原回合流程继续；
若后续生成失败，设置仍已保存，界面会提示查看待办或重试推进。

**GM 工作台 → 设置 → 本局偏好** 可将本局偏好保存为新对局默认，或把当前默认应用到本局。
这两个默认管理操作只向服务端管理员提供；只处理偏好，不包含密码、角色、奖励账本或即时操作。
不支持的规则偏好不会因“保存本局为默认”覆盖其它规则的默认值。生成进行中暂时不能应用；
待判定期间可以关闭孤注一掷，但不能同时切换叙事表现。

行动输入框内部右侧使用紧凑的一列：上方为本次技能，下方为行动按钮。文字与语音入口位于左侧，避免遮挡输入。
技能选项向上弹出，不改变输入区高度；角色没有技能时只显示行动按钮。

可用检定模式取决于规则和 GM 策略。CoC 孤注一掷绑定符合条件的失败检定，不是任意重掷；需要的 GM 同意和后果始终关联该检定。

D&D 2024 权威战斗中的可用法术取决于已准备或职业授予的法术、资源和当前触发条件。2 级以上圣武士通过职业特性获得**至圣斩**；符合条件的近战命中后，仍有附赠动作及法术位或免费次数时才出现。它不是始终可用的普通攻击按钮，长休恢复职业免费次数。这遵循当前支持的 2024 规则，不是 2014 至圣斩。

脱离战斗不会自动复活。D&D 中，战外有效治疗会同步存活但昏迷角色的权威 HP，
清除昏迷/稳定状态并重置死亡豁免；真正死亡的角色需要明确复活，普通回血和长休不能代替。
被拒绝的叙事回血不会显示为成功增血，GM 会收到需要复活的提示。权威战斗期间，叙事 HP
标签不会重复结算伤害或治疗；战斗、长休和存档重载使用同一份规则生命状态。

轻量规则和自定义规则只提供运行时明确声明的动作，不会从职业名称猜测法术机制。具体边界见[规则与骰子](rules-and-dice.md)和[自动化覆盖清单](../rulesets/dnd2024/AUTOMATION_COVERAGE.md)。

## DF Agent 与恢复

自由剧情计划、CoC 幕间成长、全程结团与角色带入见[剧情计划、幕间与结团](run-story-and-finale.md)。

房主的 DF Agent 可以查文档、读取游戏和内容状态、准备草稿。模型请求写操作时，必须经过应用里的审核确认，且继续受对应服务权限限制；普通玩家页面没有房主 Agent。确认前查看拟议改动，AI 操作使用配置的服务商，可能消耗 token。

执行操作以实际工具目录和当前应用状态为准。需要使用说明时才调用 `search_documentation`，检索本版本自带的英语或简体中文说明；开发目录使用当前本地文件。远程持续变化的手册和旧的无版本索引不决定 Agent 能做什么，也不再自动塞入每次对话。

手机游玩页的**游戏工具**汇集角色信息、场景地图和队伍，GM 工作台保留顶部独立入口；紧凑角色状态条也可打开角色抽屉。角色面板未固定且未打开时，左侧的**角色状态**边缘按钮可重新打开面板；队伍另有自己的边缘按钮。

DF Agent 的任务工作区可折叠，给手机对话区留出空间。如果拖动后找不到悬浮球，可在**管理 → 设置 → 通用 → DF Agent**恢复悬浮球位置。
队伍栏按**队伍成员 → 队伍操作 → 规则提示**排列，成员行直接标明已行动、待掷骰或暂离。
支持休息的规则会在“队伍操作”显示**队伍休息**，直接打开角色中心的休息区域；
休息进行中显示准备人数，以及**参与休息**或**查看队伍休息**。打开入口不会自动结算，仍需确认游戏内时间推进并提交。
GM 在这里**发起投掷**；玩家有未完成请求时看到**待投掷 · 数量**，有记录时可查看**投掷记录**。
空记录入口和不支持的休息入口不显示。投掷仍由服务端执行并校验当前玩家、局次和请求；已投过的玩家不会因其他人尚未投掷而被重复提示。
手机从**游戏工具 → 队伍**打开同一操作区；即使队伍抽屉关闭，仍会收到目标玩家的投掷确认弹窗，选择“稍后”后可从待投掷入口继续。GM 工作台保留管理操作，不再重复放置投掷面板。

资料册操作历史支持检查和恢复相应改动，记录仅房主可见，恢复计划也会经过校验。它不能替代版本升级备份：改程序版本前请保留完整 `data/`。
