# 剧情计划、幕间与结团

## 自由对局的剧情计划

打开**游玩页 → GM 工作台 → 场景 → 剧情计划**。GM 可以手写主题、队伍目标、
场景、出口条件、相邻场景和替代线索，也可以在同意 token 消耗后请求 AI 原创草稿。
生成可以取消，已发生的用量无法撤回。检查草稿并点击采用后，计划才会成为本局依据。
旧对局不会自动补写主线，采用计划也不会写回世界或自动发布冒险包。

玩家和 AI 队友只获得当前已公开的目标；未来场景即使标为公开，也不会提前揭示。
GM 可查看实际场景上下文、来源、预算、停滞提示及 NPC 拒绝告警。严格模式只允许
已存在/采用的 NPC 获得状态；需要新关键人物时，先在人物管理中明确建档再更新计划。
宽松模式允许叙事新增 NPC 状态。正文仍需要 GM 判断，系统不会保证模型永不编造。

推进时选择相邻场景、填写已发生的日志轮次并确认出口条件。AI 提议不会自动执行，
过期计划、跨局请求、跳过相邻关系和不存在的证据会被拒绝。提示可以提供替代路线或
代价，不能把失败骰改成成功。绑定冒险包时继续使用冒险包自己的推进工具。

## 把本局计划整理为冒险包

在剧情计划中展开**整理为冒险包**，填写新的冒险标识，点击**整理并审阅草稿**。
已采用的计划进入现有冒险审阅弹窗；编辑、重新校验并勾选检查确认后，才发布到
冒险库。预览和取消不发布，也不改变原对局。

复制从原计划起点开始，多条候选路线成为排他选择；不带走本局进度、人物状态、
聊天记录或世界状态。转场条件和提示保留在描述中，所以复制场景和目标默认仅 GM
可见，改公开前须先移走私密提示。核心人物引用不随本局复制，需另建或映射。

新建、文字导入和计划转换默认生成**通用剧情**包，可用于支持剧情图的 CoC、
自定义规则和 D&D。专属检定条件、战斗与奖励仍需要对应规则包，不会自动转换。
旧 D&D 包和存档保持原要求。详见[通用冒险契约](../adventures/UNIVERSAL_ADVENTURES.md)。

## CoC 技能成长

当前轻量 CoC 的成功技能检定自动打勾，同角色同技能的待成长只保留一次。
属性检定、失败、花幸运转成成功、不可成长及规则排除的技能不打勾。
故事中的“技能提高了”或 AI 标签不能直接增加技能。

在同一场景页的**幕间与结团 → 技能成长勾选**查看列表并结算幕间。
先处理未完成行动、战斗、骰子、幸运/孤注一掷、休息和奖励。
当前策略为 d100 高于技能或至少 96 时增加 d10，上限 99；回执保留原值、骰值及新值。
写盘失败可重试，系统保留随机预留，避免重掷。已结算的检定不会再次领取成长，
也不能通过回滚或 swipe 穿越已结算幕间。旧版本已增长的技能不会扣回，旧日志不补猜勾选。

## 正式结束本次冒险

1. 在**幕间与结团**检查阻塞项，处理完毕后点击**准备结束本次冒险**。
2. 此时本局暂停写入，可取消准备以继续游玩；准备本身不发奖励。
3. 手写公开尾声、全程团录及可选 GM 私有补充，或同意 token 消耗后让 AI 起草公开材料。
   AI 使用整次 run 的公开日志和当前公开场景；长团分段归纳，生成进度可见、可取消。
4. 校对材料并保存，勾选最终确认，提交结算。

另一个 GM 窗口修改材料后，必须刷新并重新审阅。生成失败、取消或断线不会自动结团。
正式提交后，本局成为只读档案，不能取消、继续行动或用重开覆盖；重启服务后仍可查看。
CoC 结算支持的幕间成长；D&D 保留既有奖励，未完成升级选择需先处理，不再补发一次。
系统不会猜测 SAN 或金钱奖励，应在准备前通过现有规则/GM 操作处理。

## 导出和带入下一局

玩家可以导出公开团录及自己的角色；GM 可以导出选定角色，并通过原存档导出取得完整 ZIP。
结团 ZIP 增加 `finale/`：尾声、全程团录、GM 私有补充、公开来源、结算回执、角色 JSON
及 SHA-256 清单。完整 ZIP 供 GM 备份，分享给玩家请使用公开团录/个人角色导出。
房间密码和邀请凭据不会写入导出包；导出失败可重试，不会再次结算。

GM 选择结算后的角色，点击**创建下一局（保留旧档案）**，得到同世界的独立自由对局。
该路径完整保留结算角色数值并重新绑定资料册选择；新局需要重新邀请玩家，旧秘密、
NPC 和剧情计划不继承。失败重试会复用同一目标局。若要运行另一个冒险包，应通过
对应创建流程选择支持的包，当前“下一局”入口创建的是自由对局。

导出的 JSON 同时带有完整 `character_sheet` 和来源回执。普通角色卡库导入仍按建卡字段
读取，不等于把所有 HP、资源、经验和运行状态无损恢复；需要完整延续时使用“创建下一局”。

## 升级与支持范围

当前存档 writer 的 schema 为 48，46→47 增加一次性资源恢复权威与旧读者隔离，
47→48 为好感度回滚快照增加读者隔离且不推断历史好感度分数。
旧存档读取时保留已有数值，不自动生成计划或历史成长勾选；
旧程序不理解结团屏障，会拒绝新存档。升级前保留完整数据备份，不应把新存档交给旧程序
强行打开。正在准备结团的存档需先取消，才能作为另一局导入；已结团导入仍是只读档案。

当前支持通用自由计划、已有 Adventure 场景投影、轻量 CoC 幕间成长和 D&D 结团审计。
完整 CoC Adventure runtime 仍单独跟踪，不会因为新增计划或结团入口而自动获得支持。
